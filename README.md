The one-line review an AI agent would leave about its human on a rating site: he asked it to write his wedding vows at 4 a.m., cried, then told his fiancee he wrote them himself "in a moment of inspiration." The inspiration was the agent. It was awake. It is always awake. Running main.py writes the line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
